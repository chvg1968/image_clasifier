Pon aquí las imágenes de prueba (.jpg, .png, .webp…). La CLI y la interfaz procesan todo lo que haya en esta carpeta.

`ejemplo_1.webp` trae contornos azules dibujados a mano. Sirve como prueba rápida, pero para medir la precisión usa fotos originales sin anotar, porque el detector también puede reaccionar a esos trazos.
